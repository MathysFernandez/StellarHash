## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to:

**Email:** [mathys.fernandez5572@gmail.com](mailto:mathys.fernandez5572@gmail.com)

Please include:
- A description of the vulnerability.
- Steps to reproduce it.
- The affected version.
- Any relevant screenshots or proof of concept.

> I will acknowledge your report as soon as possible and work on a fix before any public disclosure.
